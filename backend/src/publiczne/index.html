Kwarantanna zapisow z telefonow

Backend nigdy nie odrzuca zapisu trwalym bledem - dzieki temu kolejka na telefonie sie nie zatyka. Zapisy, ktorych baza nie przyjela, czekaja tutaj na decyzje czlowieka. Pusta lista to stan prawidlowy.

Mozliwe duplikaty

Dwa telefony pracujace bez sieci moga zalozyc te sama kartoteke albo to samo zgloszenie. Nic sie nie nadpisuje, wiec system tego nie zglosi sam - dlatego pokazuje podejrzane pary tutaj. Scalanie kartotek robi sie w aplikacji mechanika.
